# 0013. A hideout, not a portfolio

- Date: 2026-09-29
- Status: accepted

## Context

JM/OS began as a portfolio. An idea board framed around job hunting, with
styles invented for it, was drawn up, alongside prototypes of things from
Tiger and Leopard staged in the real site.

## Decision

JM/OS is Jincheng's own hideout. Features serve Jincheng (music, things
kept for later, looking back, idling), not recruiters. It's mostly open
to visitors, with a few rooms only Jincheng can enter, locked by the
database. New things are only what existed in Tiger or Leopard, drawn
with the same Aqua styles and the ryOS icon set. The job-hunting board
and its invented styles were rejected.

## Consequences

- From the prototypes Jincheng kept all seven; they're built one pull
  request each ([ROADMAP.md](../../ROADMAP.md)), and "the interaction and
  the UI have to be done well".
- The owner's rooms rest on [0014](0014-the-owner-is-a-database-fact.md).
